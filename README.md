# Hi, I'm Othniel 👋

I'm a Computer Science graduate from TU Dublin, Ireland, with a strong interest in software engineering and building modern, user-focused applications.

I enjoy working across the full stack, from creating responsive interfaces with React and TypeScript to developing backend services, databases and APIs. I'm particularly interested in combining software engineering with AI and machine learning to build practical products.

I recently built:

- **The Alternative** - A fashion discovery and virtual wardrobe platform using image similarity, personalised recommendations and behavioural context to help users discover clothing and build outfits.

- **Music Visualiser** - An interactive music visualisation project that transforms audio into dynamic visual experiences.
